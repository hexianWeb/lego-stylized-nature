# 2.5D 街机飞行：初版计划

目标是让同一片积木地形支持两种节奏：只享受飞行，或在探索中遭遇敌机。切换视角、开启战斗和触发救援都不应重建地形。

**当前进度：M1 已接入主场景；下一项为 C01（可选敌机遭遇）。** 玩家默认驾驶重构前的积木飞机 `public/model/player/fly.glb`，原有材质、引擎挂点和翼尖拖尾随新飞控运动。`WorldConfig.player.aircraft.appearance` 默认为 `model`；13 层切片机身保留为显式 `sprite` 配置。两种外观使用同一套飞行状态。

## 第一阶段：一趟值得反复玩的试飞

从秋林或山谷上空出发，松手保持巡航；压坡绕开山丘，加速爬升，从追尾视角做一个完整后空翻，再切入驾驶舱俯冲、拉起。**全程没有敌机也能完成验收**。第二阶段在这条航线上加入可重复的遭遇；第三阶段补齐坠机和接机。

### 重构前的约束与实现选择

- 旧的 `stepAircraftMotion()` 每帧将 `state.position.y` 写回配置高度。M1 让俯仰改变航迹，区分出生高度、当前高度和离地高度。沿用 `+X` 为初始机头、`Y` 为高度、`+Z` 为初始右方的世界坐标。
- `PlayerAircraft.js` 是 `World` 的玩家入口，运动状态作为唯一位置来源；相机、机体、喷焰、声音、小地图都读取该状态。翻滚保持小地图航向，空翻走出竖直弧线。
- `src/world/world.js` 以玩家的 `x/z` 调度区块。地表查询应读 `ChunkManager.activeSlots` 中的 `TerrainMap`（考虑负坐标、`origin` 和 `halo`），整图模式读 `world.terrainMap`。地形未就绪时用最近一次有效地表高度作保护参考，暂停坠机判定，避免加速跨区块时误触发弹射。
- `Renderer.attachPipeline()` 和区块系统都持有 `worldCamera.instance`。三个镜头共享这台相机，切换时插值相机位姿，而不是换场景、换相机实例或调用 `World.regenerate()`。

每行都是可单独审查、试飞或测试的改动。M1 完成后即可交付第一阶段；M2 与 M3 都依赖 M1，但可以独立体验。

| C01 · 发现敌机 | `World` 按场景配置启动遭遇，在前方生成有辨识度的敌机；敌机能离场并再次出现。 | M1 | 一次航程内可以接近或绕过敌机；离场后回收实体，关闭空战时没有遭遇和提示。 |

| R02 · 接机与交还 | 新机飞抵落点，经过可见的接机动作后恢复当地的飞行状态。 | R01 | 接机前不能开火或驾驶，接走后可继续操作；暂停冻结救援，各阶段重置均能清理伞与接机。**交付 M3。** |

**下一项 C01 的第一趟试飞**：同一个种子分别加载两次；在自由飞行配置中一路巡航，在遭遇配置中看到第一架敌机，转向绕过后继续探索。敌机离场后应清理，回出生点应重置遭遇。这个验收不依赖射击或救援。

### 首版操作约定（飞行已接入，空战待 M2）

| 意图 | 键鼠 | 触屏 |
| --- | --- | --- |
| 转向、爬升 / 俯冲 | `A/D` 转向，`S` 拉起、`W` 下压；方向键等价，也可用鼠标偏离中立区操纵，`invertY` 可反转 | 左杆横向转弯，纵向拉起 / 下压 |
| 加速、翻滚 | `Shift` 或长按左键加速；短点左键翻滚。参考作以约 0.2 秒区分点按和长按。 | 按住加速键；轻点飞行区域翻滚 |
| 前 / 后空翻 | `F` 后翻、`G` 前翻；也支持加速时持续拉杆 / 推杆 | 空翻按钮，或加速配合满杆 |
| 视角、暂停 | `Space` 切镜，`P` 暂停；音效保留工具栏入口 | 视角与暂停按钮 |
| 空战 | 按住右键发射机炮；敌机保持在前方直到锁定，再按 `M` 发射导弹 | 按住机炮、点按导弹；仅在空战场景显示 |

旧版 `Space` 暂停和 `M` 静音已迁移为 `P` 暂停、`U` 静音；触屏摇杆现在控制转向与俯仰。手柄可以在同一指令接口上扩展。

## 场景矩阵

拟在 `src/world/WorldConfig.js` 增加两个独立开关：`gameplay.combat.enabled` 与 `gameplay.crash.enabled`。第一阶段演示两个都关。机体受击是事件，是否启动救援由坠机配置决定；场景关闭空战时不创建敌机、弹体或战斗 HUD。

| 空战 | 坠机 | 预期体验 |
| --- | --- | --- |
| 关 | 关 | 纯飞行与特技；贴地时自动保护。 |
| 关 | 开 | 自由飞行；持续俯冲触地可体验完整救援。 |
| 开 | 关 | 允许击落敌机、闪避和受击；机体耗尽时给予短暂保护后恢复，不进入救援。 |
| 开 | 开 | 完整的探索、交战、逃生和返航循环。 |

## 参考边界

- [fighter-fly](https://github.com/AryanRajMaurya/fighter-fly)：参照持续前飞、点击翻滚 / 长按加速、三镜头，以及像素切片随姿态旋转的读感。
- [UI8 Fly](https://remix.ui8.ai/fly) 与提供的 `fly.txt`：参照持续拉杆触发空翻、锁定进度、来袭时机和弹射接机的操作节奏。`fly.txt` 是输入与界面层，导入的底层场景未包含在文件内。
- 默认沿用项目原机体、Three.js 世界与区块地形；飞行模拟、可选切片机身、敌机行为与救援状态机在本项目中实现。
