# 中景地形对照

运行 `pnpm dev`，打开 `/?trial=mixed#debug`，按空格从俯视切到追尾，再按一次进入驾驶舱。展开 **Chunks → Midground**。对着同一段山脊切换 **Geometry**，等第一圈完成替换后比较：

| 选项 | 中景地形 |
| --- | --- |
| Stepped surface（默认） | 每 6×6 格采样，高度按 2 层取整。只生成顶面、露出的台阶侧壁和区块边缘的封边。 |
| Same-density boxes | 完全相同的采样、颜色、材质和裁剪范围，每个采样块用一个完整的实例化 Box。用于隔离几何成本。 |
| Original coarse boxes | 恢复原占位层，每 12×12 格采样，高度按 6 层取整。 |

前两档可以单独切换 **Brick seams**。顶面砖缝按地形 cell 尺寸重复，侧面按实际砖层高度重复；细到屏幕分辨不出来时淡出。范围和默认值在 `src/world/WorldConfig.js` 的 `chunks.placeholder` 中。中景只在详细窗口外一圈构建，进入详细窗口时跟随积木的逐列进度退场；最远一圈仍用原占位。

## 一次桌面短测

Windows Chrome / WebGPU（NVIDIA Lovelace），960×540，像素比 1。相同 seed，在混合生态试飞场景用追尾镜头从 `(13, 4.5, 36)` 沿 X 飞到 `(55, 4.5, 36)`，每档预热后取 180 帧。CPU 和 GPU 是整帧各自的中位耗时，P95 是两次显示帧之间的间隔。

| 方案 | CPU 中位 | GPU 中位 | 帧间隔 P95 |
| --- | ---: | ---: | ---: |
| 原粗盒 | 6.2 ms | 3.23 ms | 16.9 ms |
| 同密度实例盒 + 砖缝 | 5.9 ms | 3.43 ms | 16.8 ms |
| 台阶网格 + 砖缝 | 6.0 ms | 3.47 ms | 16.8 ms |

另在相同低视角、只绘制占位层的火山路线跨越四个 chunk，取 160 帧。开启相同砖缝时，实例盒与台阶网格提交的三角形中位数分别为 **15,553 / 12,473**，绘制调用中位数都是 **5**；GPU 中位耗时分别为 **0.55 / 0.49 ms**。这说明删去内侧面确实减少了几何工作，但整场景没有测出明确提速；原粗盒的 GPU 成本仍更低。移动设备请按目标分辨率单独复测。
